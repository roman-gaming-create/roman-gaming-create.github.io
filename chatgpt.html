Разработка управления кубиком в Unity на C#

Мини-игра для Windows: перемещение с помощью WASD, прыжок на Space и идеи для расширения игровых механик.

Создадим простой контроллер персонажа-кубика. Скрипт использует Rigidbody для физики, считывает клавиши и позволяет прыгать только тогда, когда персонаж стоит на земле.

Глава 1. Подготовка персонажа в Unity

  1. Создайте персонажа. В Unity выберите GameObject → 3D Object → Cube и переименуйте объект в Player.
  2. Добавьте Rigidbody. Выберите кубик и нажмите Add Component → Rigidbody. Этот компонент отвечает за физику, гравитацию и взаимодействие с препятствиями.
  3. Подготовьте уровень. Создайте поверхность через 3D Object → Plane. Убедитесь, что у поверхности есть коллайдер, а кубик расположен немного выше неё.
Важно: у кубика и поверхности должны быть коллайдеры. Для кубика обычно подходит Box Collider, для пола можно использовать стандартный коллайдер объекта Plane.

Глава 2. C#-скрипт управления персонажем

Создайте файл PlayerController.cs в папке Assets/Scripts и прикрепите его к объекту Player.

В этом варианте Update() считывает нажатия клавиш, а FixedUpdate() обновляет физическое движение.

using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class PlayerController : MonoBehaviour
{
    [Header("Movement Settings")]
    [SerializeField] private float moveSpeed = 5f;

    [Header("Jump Settings")]
    [SerializeField] private float jumpForce = 7f;

    [Header("Ground Check")]
    [SerializeField] private Transform groundCheck;
    [SerializeField] private float groundCheckRadius = 0.15f;
    [SerializeField] private LayerMask groundLayer;

    // Ссылка на физический компонент персонажа
    private Rigidbody rb;

    // Направление движения, полученное от игрока
    private Vector3 moveInput;

    // Флаг: находится ли персонаж на земле
    private bool isGrounded;

    // Запрос на прыжок, чтобы обработать его в FixedUpdate
    private bool jumpRequested;

    private void Awake()
    {
        // Получаем Rigidbody у текущего объекта
        rb = GetComponent<Rigidbody>();

        // Запрещаем кубику заваливаться и кувыркаться
        rb.constraints = RigidbodyConstraints.FreezeRotation;
    }

    private void Update()
    {
        // Считываем нажатия WASD.
        // Horizontal: A/D, Vertical: S/W.
        float horizontal = Input.GetAxisRaw("Horizontal");
        float vertical = Input.GetAxisRaw("Vertical");

        // Создаём направление движения по горизонтальной плоскости
        moveInput = new Vector3(horizontal, 0f, vertical).normalized;

        // Проверяем, касается ли персонаж земли.
        // GroundCheck должен находиться у нижней грани кубика.
        isGrounded = Physics.CheckSphere(
            groundCheck.position,
            groundCheckRadius,
            groundLayer,
            QueryTriggerInteraction.Ignore
        );

        // Разрешаем прыжок только при нажатии Space на земле
        if (Input.GetKeyDown(KeyCode.Space) && isGrounded)
        {
            jumpRequested = true;
        }
    }

    private void FixedUpdate()
    {
        // Сохраняем текущую вертикальную скорость,
        // чтобы движение не отменяло падение и прыжки.
        Vector3 velocity = rb.velocity;

        // Меняем только скорость по горизонтальным осям
        velocity.x = moveInput.x * moveSpeed;
        velocity.z = moveInput.z * moveSpeed;

        rb.velocity = velocity;

        // Обрабатываем прыжок в физическом цикле
        if (jumpRequested)
        {
            // Сбрасываем вертикальную скорость перед прыжком,
            // чтобы высота прыжка была более предсказуемой.
            velocity = rb.velocity;
            velocity.y = 0f;
            rb.velocity = velocity;

            // Придаём кубику скорость вверх
            rb.AddForce(Vector3.up * jumpForce, ForceMode.Impulse);

            // Сбрасываем запрос, чтобы не прыгать повторно
            jumpRequested = false;
        }
    }

    // Визуализация области проверки земли в редакторе Unity
    private void OnDrawGizmosSelected()
    {
        if (groundCheck == null)
            return;

        Gizmos.color = Color.green;
        Gizmos.DrawWireSphere(
            groundCheck.position,
            groundCheckRadius
        );
    }
}

Как работает скрипт

ЭлементНазначение
moveSpeedСкорость передвижения кубика.
jumpForceИмпульс прыжка.
moveInputНаправление движения, полученное из ввода игрока.
isGroundedРезультат проверки, находится ли персонаж на земле.
jumpRequestedЗапрос на прыжок, который будет обработан в физическом цикле.
RigidbodyОбеспечивает физическое движение и гравитацию.
  • .normalized ограничивает длину вектора движения, поэтому движение по диагонали не будет быстрее движения прямо.
  • При обычном передвижении изменяются только горизонтальные компоненты скорости X и Z. Вертикальная скорость сохраняется, поэтому кубик продолжает падать и прыгать.
Примечание о версиях Unity: код использует старую систему ввода Input.GetAxisRaw и Input.GetKeyDown, а также свойство Rigidbody.velocity. В новых версиях Unity может быть доступно свойство linearVelocity; если редактор выдаёт предупреждение об устаревшем API, замените обращения к rb.velocity на rb.linearVelocity.

Глава 3. Настройка прыжков и земли

Для проверки контакта с землёй скрипту нужен вспомогательный объект.

  1. В иерархии Unity нажмите правой кнопкой на Player, выберите Create Empty и назовите объект GroundCheck.
  2. Установите его локальную позицию примерно в (0, -0.5, 0), если кубик имеет размер 1 × 1 × 1. Объект должен находиться у нижней грани кубика.
  3. Создайте слой Ground и назначьте его полу и тем поверхностям, на которых разрешено прыгать.
  4. Выберите Player и в компоненте PlayerController перетащите объект GroundCheck в поле Ground Check. В поле Ground Layer выберите слой Ground.

Рекомендуемые начальные параметры

ПараметрНачальное значениеКак влияет
Move Speed5Определяет скорость передвижения.
Jump Force7Определяет силу импульса прыжка.
Ground Check Radius0.15Радиус сферы, проверяющей землю.

Параметры можно изменять в Inspector. Высота прыжка зависит не только от jumpForce, но и от гравитации и настроек физики проекта.

Глава 4. Как усложнить механику персонажа

Основная идея: рывок (Dash)

Добавьте возможность быстро перемещаться на короткое расстояние по нажатию Left Shift.

  • Игрок нажимает Left Shift.
  • Кубик резко ускоряется в направлении движения.
  • Рывок длится короткое время, например 0,2 секунды.
  • После использования начинается перезарядка, например 1,5 секунды.
  • Пока способность перезаряжается, повторный рывок недоступен.

Рывок расширит возможности прохождения: с его помощью можно преодолевать широкие пропасти в комбинации с прыжком, быстро проходить опасные участки и избегать движущихся препятствий.

Другие идеи для развития

1. Двойной прыжок

Разрешите персонажу прыгнуть второй раз в воздухе. Для этого можно добавить счётчик оставшихся прыжков, который сбрасывается при приземлении.

2. Скольжение

При нажатии Left Ctrl кубик временно уменьшает высоту коллайдера и проскальзывает под низкими препятствиями. Не забудьте проверять, что над персонажем достаточно места для возвращения к обычному размеру.

3. Ускоряющие платформы

При соприкосновении со специальной поверхностью кубик получает дополнительную скорость. Это позволит создавать маршруты с прыжками, ускорениями и точными приземлениями.

Глава 5. Проверка и возможные проблемы

После добавления скрипта запустите игру кнопкой Play и проверьте управление.

ДействиеКлавишаОжидаемый результат
ВперёдWДвижение по оси Z.
НазадSДвижение в отрицательном направлении оси Z.
ВлевоAДвижение в отрицательном направлении оси X.
ВправоDДвижение в положительном направлении оси X.
ПрыжокSpaceПрыжок, если персонаж находится на земле.

Если кубик не реагирует на клавиши, проверьте следующее:

  • Скрипт PlayerController прикреплён к кубику.
  • В поле Ground Check назначен объект GroundCheck.
  • В поле Ground Layer выбран правильный слой.
  • В настройках проекта Edit → Project Settings → Player → Other Settings → Active Input Handling разрешена работа старой системы ввода (Input Manager) или выбрано Both. Приведённый код использует старый Input Manager.
  • У Rigidbody включена гравитация (Use Gravity), а в ограничениях не заморожены перемещения по X, Y или Z.
  • Пол находится на слое, который указан в Ground Layer, и сфера проверки действительно касается поверхности.

Итог

Получился базовый контроллер для платформера в Unity: он поддерживает движение по четырём направлениям, физический прыжок и проверку контакта с землёй.

Рекомендуемый порядок развития игры: сначала добавить рывок, затем двойной прыжок, а после этого — специальные платформы и препятствия, требующие комбинировать способности. Так управление останется простым, а игровой процесс постепенно станет интереснее.
