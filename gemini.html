Ниже представлена структура ответа, разделенная на главы: от настройки сцены и кода до идей по развитию проекта.

### Глава 1: Подготовка сцены в Unity

Перед тем как вставить скрипт, убедитесь, что ваш персонаж-куб правильно настроен:
1. Создайте 3D-объект **Cube** (GameObject -> 3D Object -> Cube) и переименуйте его в `Player`.
2. Добавьте ему компонент **Rigidbody** (*Component -> Physics -> Rigidbody*).
   * В компоненте Rigidbody раскройте вкладку **Constraints** и поставьте галочки на **Freeze Rotation X, Y, Z**. Это нужно, чтобы куб не кувыркался при движении, а скользил (если вам не нужна механика качения).
3. Создайте пустой объект внутри куба (сделайте его дочерним), назовите его `GroundCheck` и сместите немного ниже нижнего основания куба.
4. Создайте слой **Ground** и назначьте его всем объектам пола и препятствий.

### Глава 2: C# Скрипт движения (`PlayerController.cs`)

Создайте новый C# скрипт с именем `PlayerController` и вставьте в него следующий код:

```csharp
using UnityEngine;

public class PlayerController : MonoBehaviour
{
    [Header("Параметры движения")]
    [Tooltip("Скорость перемещения куба")]
    public float moveSpeed = 7f;
    [Tooltip("Сила прыжка")]
    public float jumpForce = 5f;

    [Header("Проверка земли")]
    [Tooltip("Объект внизу куба для проверки касания земли")]
    public Transform groundCheck;
    [Tooltip("Радиус сферы проверки земли")]
    public float checkRadius = 0.3f;
    [Tooltip("Слой, который считается землей")]
    public LayerMask groundLayer;

    // Приватные переменные для внутренней логики
    private Rigidbody rb;
    private float inputX;
    private float inputZ;
    private bool isGrounded;
    private bool jumpRequested;

    void Start()
    {
        // Получаем ссылку на Rigidbody персонажа
        rb = GetComponent<Rigidbody>();
    }

    void Update()
    {
        // 1. Считываем ввод с клавиатуры (WASD / Стрелочки)
        // GetAxisRaw дает мгновенный отклик без сглаживания
        inputX = Input.GetAxisRaw("Horizontal"); // A/D
        inputZ = Input.GetAxisRaw("Vertical");   // W/S

        // 2. Проверяем, находится ли куб на земле
        // Создаем невидимую сферу в точке groundCheck и проверяем, пересекает ли она слой groundLayer
        isGrounded = Physics.CheckSphere(groundCheck.position, checkRadius, groundLayer);

        // 3. Отслеживаем нажатие пробела для прыжка
        // Нажатие считывается в Update, чтобы не пропустить ввод
        if (Input.GetButtonDown("Jump") && isGrounded)
        {
            jumpRequested = true;
        }
    }

    void FixedUpdate()
    {
        // Вся физика должна обрабатываться в FixedUpdate!
        Move();

        if (jumpRequested)
        {
            Jump();
        }
    }

    private void Move()
    {
        // Вычисляем направление движения относительно глобальных осей
        Vector3 moveDirection = new Vector3(inputX, 0f, inputZ).normalized;

        // Применяем скорость к Rigidbody, сохраняя текущую скорость по оси Y (гравитацию)
        Vector3 targetVelocity = moveDirection * moveSpeed;
        rb.velocity = new Vector3(targetVelocity.x, rb.velocity.y, targetVelocity.z);
    }

    private void Jump()
    {
        // Прикладываем импульсную силу вверх
        rb.AddForce(Vector3.up * jumpForce, ForceMode.Impulse);
        jumpRequested = false; // Сбрасываем флаг прыжка
    }

    // Отрисовка сферы проверки земли в редакторе (для удобства настройки)
    private void OnDrawGizmosSelected()
    {
        if (groundCheck != null)
        {
            Gizmos.color = Color.red;
            Gizmos.DrawWireSphere(groundCheck.position, checkRadius);
        }
    }
}
```

### Глава 3: Инструкция по настройке в Inspector

1. Навести скрипт `PlayerController` на ваш куб-игрок.
2. В инспекторе перетащите объект `GroundCheck` из иерархии в соответствующее поле **Ground Check** скрипта.
3. В поле **Ground Layer** выберите созданный ранее слой `Ground`.
4. Настройте `Move Speed` (например, 7-10) и `Jump Force` (например, 5-8).

### Глава 4: Идея для расширения механики — «Смена состояний куба»

Чтобы сделать игровой процесс более глубоким, добавим концепцию **«Материальных состояний»**. Так как ваш персонаж — куб, он может менять свои физические свойства прямо на лету (например, по нажатию клавиш `1`, `2`, `3` или при поднятии определенных бонусов).

#### Концепция: 3 Режима Куба

1. **Обычный куб (Дерево/Пластик):**
   * Стандартная скорость, стандартная прыгучесть.

2. **Тяжелый куб (Свинец):**
   * **Механика:** Масса увеличивается в 5 раз (`rb.mass`), скорость снижается, прыгать нельзя.
   * **Зачем нужно:** Может нажимать тяжелые кнопки/рычаги, его не сдувают вентиляторы на уровне, он может ломать хрупкий пол под собой, падая с высоты.

3. **Липкий/Магнитный куб (Резина/Магнит):**
   * **Механика:** Теряет возможность прыгать, но может ходить по вертикальным стенам и потолкам (изменяем направление гравитации для куба через `rb.AddForce`).
   * **Зачем нужно:** Преодоление пропастей по потолку, обход опасных ловушек на полу.

4. **Упругий куб (Слайм):**
   * **Механика:** Прыжок становится в 2 раза выше + добавляется **Двойной прыжок (Double Jump)**, но куб становится скользким (тяжелее останавливаться).
   * **Зачем нужно:** Преодоление высоких препятствий и затяжные прыжки через широкие пропасти.

#### Как это усложнит геймплей?
Игроку придется решать пространственные головоломки на скорости. 
* *Пример:* Разбежаться в **Обычном** режиме, переключиться в **Слайм** в воздухе для двойного прыжка, а при приземлении на вертикальную стену включить **Магнитный** режим, чтобы зафиксироваться на ней.
