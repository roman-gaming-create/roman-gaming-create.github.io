📘 Введение

Скрипт ниже управляет 3D-кубиком. Используется Rigidbody (без вращения), проверка земли через OverlapSphere. Конфигурация — через инспектор. Проект ориентирован на сборку Windows (Standalone).

🔧 Быстрый старт: добавьте скрипт на куб → в Ground Check перетащите пустой объект, расположенный у ног куба → укажите слой земли.

Глава 1. Скрипт CubeController

Полный, хорошо прокомментированный C# код. Скопируйте и вставьте в новый файл CubeController.cs.

using UnityEngine;

[RequireComponent(typeof(Rigidbody))]
public class CubeController : MonoBehaviour
{
    [Header("Движение")]
    [SerializeField] private float moveSpeed = 6f;      // скорость по горизонтали
    [SerializeField] private float jumpForce = 8f;      // сила прыжка вверх

    [Header("Проверка земли")]
    [SerializeField] private Transform groundCheck;     // пустой объект у ног кубика
    [SerializeField] private float groundRadius = 0.2f; // радиус сферы
    [SerializeField] private LayerMask groundMask;      // слои, считающиеся землёй

    [Header("Дополнительно")]
    [SerializeField] private bool allowDoubleJump = false; // разрешить второй прыжок в воздухе

    // --- Внутренние переменные ---
    private Rigidbody rb;
    private bool isGrounded;
    private bool hasDoubleJumped;   // использован ли второй прыжок (если разрешен)

    private void Awake()
    {
        // Получаем Rigidbody на этом же объекте. Если его нет — AddComponent.
        rb = GetComponent();

        // Отключаем вращение по осям X и Z, чтобы кубик не опрокидывался
        rb.freezeRotation = true;

        // Если groundCheck не назначен — используем сам объект (центр кубика)
        if (groundCheck == null)
            groundCheck = transform;
    }

    private void FixedUpdate()
    {
        // 1. Проверяем, стоим ли на земле
        CheckGround();

        // 2. Горизонтальное движение
        MoveHorizontal();

        // 3. Прыжок (обрабатываем здесь, чтобы корректно работало с FixedUpdate)
        if (Input.GetButtonDown("Jump"))
            Jump();
    }

    /// 
    /// Сфера вокруг groundCheck — если есть коллайдеры из groundMask, мы на земле.
    /// 
    private void CheckGround()
    {
        // OverlapSphere возвращает все коллайдеры в радиусе
        Collider[] colliders = Physics.OverlapSphere(groundCheck.position, groundRadius, groundMask);
        isGrounded = colliders.Length > 0;

        // Сброс двойного прыжка, когда снова коснулись земли
        if (isGrounded)
            hasDoubleJumped = false;
    }

    private void MoveHorizontal()
    {
        // Input.GetAxis возвращает значения от -1 до 1
        float horizontal = Input.GetAxisRaw("Horizontal"); // A/D
        float vertical   = Input.GetAxisRaw("Vertical");   // W/S

        // Нормализуем, чтобы диагональное движение не было быстрее
        Vector3 direction = new Vector3(horizontal, 0f, vertical).normalized;

        // Применяем скорость — полностью заменяем горизонтальную составляющую
        // (так персонаж мгновенно реагирует, не скользит)
        rb.velocity = new Vector3(direction.x * moveSpeed, rb.velocity.y, direction.z * moveSpeed);
    }

    private void Jump()
    {
        // Только если на земле (или разрешён двойной прыжок и он ещё не использован)
        if (!isGrounded && (!allowDoubleJump || hasDoubleJumped))
            return;

        // Добавляем вертикальную скорость, сохраняя горизонтальную
        rb.velocity = new Vector3(rb.velocity.x, jumpForce, rb.velocity.z);

        // Если были в воздухе — тратим второй прыжок
        if (!isGrounded)
            hasDoubleJumped = true;
    }

    // Визуализация радиуса проверки земли в редакторе
    private void OnDrawGizmosSelected()
    {
        if (groundCheck != null)
        {
            Gizmos.color = isGrounded ? Color.green : Color.red;
            Gizmos.DrawWireSphere(groundCheck.position, groundRadius);
        }
    }
}

🔍 Пояснения к ключевым моментам

  • RequireComponent — автоматически добавит Rigidbody.
  • freezeRotation — кубик не кувыркается.
  • OverlapSphere — не проваливается сквозь тонкие плоскости.
  • Input.GetAxisRaw — мгновенный отклик (без сглаживания).
  • allowDoubleJump — включается прямо в инспекторе.

Глава 2. Настройка в Unity (за 4 шага)

  1. Создайте куб → GameObject → 3D Object → Cube.
  2. Добавьте компоненты: Rigidbody (Mass=1, Drag=0, Constraints: Freeze Rotation X, Z) и перетащите скрипт.
  3. Ground Check: создайте пустой дочерний объект GroundCheck, поместите внизу куба (Y ≈ –0.5). Перетащите в поле скрипта. Radius = 0.2, Layer = Default (или создайте «Ground»).
  4. Пол: Plane или растянутый Cube (слой Ground). Для пола без трения — Physic Material с трением 0.
⚠️ Если куб проваливается — уменьшите groundRadius или увеличьте масштаб пола. Если прыгает сам — отключите Interpolate на Rigidbody.

🧠 Три продвинутые способности (внедряются отдельно)

  • E – Телепорт: прыжок на 3 м вперёд, кулдаун 3 с.
  • Shift – Ускорение: 3 с ×1.8 скорости, оставляет след частиц.
  • Исчезающие блоки: через 0.5 с после касания — исчезают (повторно не появляются).

Глава 4. Куда двигаться дальше

  1. Тестовый уровень: 3 платформы, 1 скользкий участок, 1 исчезающий блок.
  2. UI: счёт монет, количество смертей (TextMeshPro).
  3. Сборка: Build Settings → Player → Resolution and Presentation — отключить курсор.
  4. Профилирование: Window → Analysis → Profiler — следить за коллайдерами.
  5. Полировка: частицы приземления, звуки шагов (разные поверхности), Cinemachine FreeLook камера.
